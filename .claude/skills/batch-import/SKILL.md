# 批量录入物品照片

流程：看照片 → 生成录入清单 → 用户确认 → 检查 → 写入数据仓库 → 收尾。
**用户确认之前，绝不写入。**

## 0. 准备

```
python3 tools/import_items.py --options
```

列出现有的位置、标签、字段建议和已用编号。清单里只能用这里列出的位置和标签。
报"拿不到 GitHub 令牌"时，让用户在 Claude Code 里输入 `! gh auth login`。

照片文件夹由用户给出，一般是一个柜子一批（如 `~/Desktop/物品照片/当季衣柜/`）。

## 1. 看照片，识别物品

用 Read 工具逐张看（一次 5～10 张）。HEIC 你可能读不了：先用 `sips -s format jpeg x.heic --out /tmp/x.jpg` 转一份临时 JPG 来看，清单里仍写原文件名（脚本会自己转）。

- **一件物品通常对应一张或几张照片**。连续几张拍同一件东西（正面、背面、标签特写），合并成一条，最清楚的整体照放第一张，它会成为封面。
- 一张照片里有好几件不同的东西：拆成多条，可以共用这张照片。拿不准是一件还是一套时，问用户。
- **编号一般不用填**：脚本写入时按第一个标签的类别自动给号（如电子产品 `100-005`），并放进「待打印」；衣服、运动服、鞋这类「不贴标签」的类别不给号。所以**第一个标签要选准**，它决定编号类别。
  - 照片里已经贴着本系统的标签（如 `100-003`）：读出来填进 `assetId`。看不清就填 `"?"` 请用户补，**绝不猜**。
  - 要贴标签的类别里，某件不想贴（比如太小）：加 `"noLabel": true`。
- **名称**写具体：`颜色 + 品类 + （品牌）`，如 `黑色羽绒服（优衣库）`。看不出品牌就不写。
- **标签**只用 `--options` 列出的，拿不准就问。
- **字段**：衣服、运动服、鞋在 `fields` 里填看得出的 `季节`、`颜色`；`尺码` 只有看得到尺码标时才填。零食食品、药品急救包装上看得到保质期的，填 `保质期`（`2027-03-01`）。
- **发票、收据、保修卡**放进对应物品的 `receipts`，不要当成单独的物品。看得清的购买日期、价格、店铺，填 `purchaseDate`、`purchasePrice`、`purchaseFrom`。
- 电子产品看得到的型号、序列号，填 `modelNumber`、`serialNumber`。
- 价格、日期、序列号看不到就不填，**不要编**。
- 同一种消耗品有很多个（抽纸、牙膏），记成一条，用 `quantity` 表示数量。

## 2. 生成录入清单

在照片文件夹里写 `manifest.json`：

```json
{
  "location": "当季衣柜",
  "items": [
    {
      "name": "黑色羽绒服（优衣库）",
      "tags": ["衣服"],
      "photos": ["IMG_0001.jpg", "IMG_0002.jpg"],
      "manufacturer": "优衣库",
      "fields": {"季节": "冬", "颜色": "黑色", "尺码": "L"}
    },
    {
      "name": "AirPods Pro 2",
      "tags": ["电子产品"],
      "assetId": "000-101",
      "location": "书桌抽屉",
      "photos": ["IMG_0003.jpg"],
      "receipts": ["IMG_0004.jpg"],
      "manufacturer": "Apple",
      "serialNumber": "ABC123",
      "purchaseDate": "2025-09-20",
      "purchasePrice": 1899,
      "warrantyExpires": "2026-09-20"
    }
  ]
}
```

- 顶层 `location` 是这批的默认位置；某件在别处就用它自己的 `location`。写柜子中文名就行。
- 可用字段：`name`、`tags`、`assetId`、`noLabel`、`quantity`、`location`、`description`、`photos`、`receipts`、`manufacturer`、`modelNumber`、`serialNumber`、`purchaseDate`、`purchasePrice`、`purchaseFrom`、`warrantyExpires`、`notes`、`fields`。

## 3. 给用户确认

用表格列出全部条目：序号、编号（没填的写「自动」或「不贴」）、名称、标签、位置、照片文件、其他识别到的信息。下面单独列出：编号是 `"?"` 的、你拿不准的地方、没用上的照片。

按用户的修改更新清单，再给用户看一遍改过的部分。用户明确说"可以""确认"之后才进行下一步。

## 4. 检查并写入

```
python3 tools/import_items.py "<文件夹>/manifest.json" --dry-run
python3 tools/import_items.py "<文件夹>/manifest.json"
```

- dry-run 报错就按提示修正清单；涉及用户信息的（比如编号被占用），先问用户。
- 正式写入是整批一次提交：要么全部成功，要么什么都不写。失败了修好再运行即可。
- 成功后清单里每件都会记下 `id`，重复运行会跳过。

## 5. 收尾

1. 告诉用户录了几件、新给了哪些编号（脚本会列出来），提醒他们到网页「更多 → 待打印标签」导出 Excel 用汉码打印，贴好后标记已打印。
2. 照片已经存进数据仓库了。问用户要不要删掉本地这批照片（用户不想在本地留数据）；得到同意再删。
